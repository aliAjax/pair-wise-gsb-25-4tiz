# hxwl-11 设备放行台 · 眼科验光记录

开工先校准、校准在有效期内才允许接新顾客的门店工作台。

## 业务规则

- 开工录入：设备编号、标准片球镜/柱镜、仪器实测球镜/柱镜、校准人、校准时刻。
- 判定：球镜或柱镜任一偏差**超过 0.12D**，设备立即**停用**；修好后**重新校准**合格才能恢复放行。
- 时效：校准有效期 **2 小时**，超时看板自动转“校准过期”。
- 保存顾客验光前必须选设备；设备停用或校准超过两小时时**只能存草稿**并提示未通过原因，停用设备在下拉中不可选。
- 草稿可在设备重新校准放行后打开续编，再次保存通过后转为“已保存”。
- 校准资料、放行状态、顾客记录（含草稿）均存在本机，重开页面仍在；已保存记录随时可查。

## 技术栈

React + Vite + TypeScript + CSS，无新增依赖，纯 `localStorage` 本地留档。

## 目录结构（按职责分开）

```
src/
  types.ts                     领域数据类型（校准 / 设备 / 验光记录 / 留档）
  rules.ts                     判定规则：0.12D 偏差阈值、两小时时效、放行闸门
  storage.ts                   本地留档：localStorage 读写
  components/
    CalibrationForm.tsx        校准资料录入页块
    DeviceBoard.tsx            设备放行看板
    ExamForm.tsx               顾客验光录入与保存闸门
    RecordList.tsx             已保存 / 草稿记录查询
  App.tsx                      页面组装与状态
  styles.css
```
